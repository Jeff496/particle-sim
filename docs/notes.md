- !ctx.is_static and ctx.is_passable generate different behavior due to the check for a free block to the immediate side of pixel in ctx.is_passable. This means checking !ctx.is_static allows for pure diagonal movement while ctx.is_passable requires a free space to the side along with the requirement that the diagonal be open. Using !ctx.is_static allows for a "shear" effect within a powder pile which behaves more realistically.
